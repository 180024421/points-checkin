# 积分签到工具（CheckinTool）使用说明

## 功能

- 卡密激活（`app_key=points-checkin`，设备绑定）
- 多账号入池：
  - **自助**：官方客户端切号后点「采集」/「粘贴 Trae token」
  - **统一登录**：导入账密 → 优先官方登录 API → 失败再有头 Playwright（可过验证码）
- **本机跑**：早晚双窗口调度 + 托盘常驻 + 开机自启
- **服务器代跑**：上传 **token**（不上传明文账密）；可「立即服务器代跑」
- **今日看板**：已跑 / 未跑 / 失败
- **积分记录** + **实时日志**（可清理）
- 失败自动重试（网络 / Trae 9074）

## 安装与启动

开发调试：

```bat
pip install -r requirements.txt
playwright install chromium
python -m checkin_tool
```

对外交付：打成 EXE

```bat
build_gui.bat
```

产物：`dist\CheckinTool.exe`（无控制台窗口）。首次若用统一登录，本机仍需安装过 Chromium（`playwright install chromium`）。

## 导入账密统一登录

1. 「导入账密」填产品（workbuddy / traework）+ 邮箱或手机 + 密码；可勾选立即登录
2. 批量格式每行：`provider,username,password[,label]`
3. 「统一登录(全部账密)」或「管理已存账密」里对单条登录
4. 成功后自动写入账号列表，可直接本机签 / 代跑

说明：WorkBuddy / Trae 多为 OneID / OAuth，纯密码 API 常常不可用，工具会自动开浏览器；遇扫码或强验证码时请改回「采集 / 粘贴 token」。账密仅本机 DPAPI 加密。

## 多号怎么采（自助）

1. 打开 WorkBuddy / TraeWork，登录号 A → 点「采集」
2. 退出并登录号 B → 再点「采集」
3. 列表会出现两个账号；可分别设「本机跑 / 服务器代跑」

TraeWork 若提示无法自动解密 token：先打开客户端登录，再「粘贴 Trae token」（设备头会自动带上）。

## 今日与日志

- 「今日看板」看谁跑了、谁还没跑、谁失败
- 「积分记录」看每次查询/签到拿到的积分与连签
- 「实时日志」看正在跑的过程；可清理实时日志或跑批日志
