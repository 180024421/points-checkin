数据备份与恢复

五步跑通

1 · 激活系统设置里填卡密并「保存并激活」。授权与本机绑定，一台设备一个坐席。
2 · 导入账号装好 WorkBuddy / Trae CN 客户端并登录，回「账号管理」点「从客户端导入」；Trae CN 开启自动捕获后登录即入库，也可粘贴 token。
3 · 选模式本机 = 用这台电脑的登录态签；代跑 = 只上传 token 到服务器，关机也能签。列表每行可单独切换。
4 · 设节奏「签到设置」里定每日时间、账号间随机间隔和积分告警阈值，开启自动签到后到点自己跑。
5 · 看结果「今日签到」看谁签了谁没签，「签到记录」看积分流水；底部运行日志有异常会直接写出来。

常见问题

Token 过期：列表 Token 列会标红，重新在客户端登录一次即可（Trae CN 开了自动捕获就不用手动采集）。

新增账号被拒：套餐坐席已满或坐席全部到期。停用不用的账号、续卡或买卡；离线取不到额度时只能照常签到，暂时不能新增。

整点没跑：签到时间在设定值后 0~2 分钟内随机触发，且晚窗还会补漏，不必守着。
